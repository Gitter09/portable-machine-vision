## Fixed policy used before measuring results

- Blue substrate HSV bounds: **[90,65,30] to [140,255,255]**, inherited from the
  previous colour experiments, not selected from reviewed polygons.
- Canny: grayscale, 5x5 Gaussian sigma 1.2, **30/90 L2**; existing contour branch
  uses one 3x3 closing pass, the previous strongest development setting.
- Colour gate: >=500 blue pixels and >=15% blue fraction inside a candidate.
- Group branch: **15x15 closing** joins small gaps; hull/minimum rectangle gives
  candidate seed. Long side 100..300 px, short side 25..120, aspect 1.5..5,
  area 2,000..25,000 px²; same blue evidence requirements.
- Choose the strongest seed by blue-pixel support. If another plausible seed
  has >=75% support, return **unknown**, not a forced crop.
- Local refinement: take Canny pixels within **32 source pixels** beyond the seed
  along both rectangle axes. Require >=30 edge pixels. Fit an enclosing rectangle
  to those edges **and the seed corners**, so it cannot shrink away the seed.
  Remote bracket/plate edges cannot relocate the crop outside that local search.
- Add **16 source pixels** padding; refuse crops beyond image bounds. Warp original
  colour pixels and make an aspect-preserving 512x256 letterboxed preview.

All three variants were specified and run once; no parameter sweep or subsequent
per-frame adjustment. Policy and implementation hashes recorded in results.
No fixed plate-interior mask was needed. Canny currently computes full-frame
edges in the offline helper; local point selection is not a runtime optimization
or a board-performance claim.
