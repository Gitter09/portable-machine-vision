# Summit dashboard surface

Mode: Operate. Target: frontend/index.html. Audience: visitors viewing an external summit monitor; presenter controls remain secondary.

## Direction contract

THESIS: A real component finding is the exhibit. The inspection image, not decorative charts or a manufactured product verdict, leads.

OWN-WORLD: Owner-pinned white industrial interface, BITS navy identity, simple labelled status colours, consistent local Lucide icons, generous spacing and keyboard focus.

STORY: “See what’s missing. Right at the edge.” The PCB is a demonstration of component presence detection, not proof of an arbitrary customer's application.

FIRST VIEWPORT: Logo/header, approved two-line message, large exact-frame inspection left and latest component detections right; telemetry, smaller live preview, and change history below. Presenter controls expose scenario selection. Signature interaction: changing a scenario changes both schematic component presence and corresponding detection findings. No decorative motion.

FORM: seed: none (pinned). User approved the proposed composition and “white industrial interface, with a focus on accessibility”, then instructed implementation. Static browser approach extends the existing repository UI.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
